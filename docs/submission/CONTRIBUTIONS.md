# Team contributions

The project was organized into five responsibilities. Team identities are
supplied by the Devpost roster; this table records the allocation without
guessing names from Git authorship.

| Component | Contribution |
|---|---|
| 1 — Intent/query understanding | Intent classification, slot extraction, query parsing and handoff contracts. |
| 2 — Retrieval | Catalog indexes, keyword/category/evidence routes, candidate provenance and research retrieval resources. |
| 3 — State/context | Session and slot models, state/profile concepts, context representation and multi-turn tests. |
| 4 — Ranking/clarification | Contextual reranking, profile-aware scoring, policy research and optional model experiments. |
| 5 — Evaluation/integration | Official kit and baseline validation, versioned adapters, orchestration and feedback, integration tests, submission packaging, evaluation and demo documentation. |

Not all research variants are active in the submitted CPU entry. Integration-
specific work includes explicit slot operations, a structured state consumer,
state-adaptive question decisions, recall-compatible and strict candidate modes,
conservative budget/exclusion checks, bounded questions/retries, and reproducible
public-set ablations.

Codex assisted with integration implementation, review, testing and document
preparation. The team remains responsible for reviewing the code, validating
the results and explaining the submitted implementation.
